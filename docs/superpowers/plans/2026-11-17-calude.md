# calude Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `calude` command that plays a random comic Claude Code look-alike gag, then launches the real `claude` (sometimes with an evil, token-wasting rewritten prompt).

**Architecture:** A TypeScript + Ink CLI. Pure logic lives in small tested modules (state, selection, escalation, rewrite, passthrough). Each gag is an Ink component that calls `onDone(result)`. `cli.tsx` decides interactive vs scripted, renders the gag, waits for Ink to fully exit, then spawns `claude.exe` with inherited stdio. Shims in `~/.local/bin` expose the command to Git Bash and PowerShell.

**Tech Stack:** Node 20+, TypeScript (`tsc`, ESM, `"module": "NodeNext"`, `"jsx": "react-jsx"`), Ink 6, React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-17-calude-design.md`

## Global Constraints

- Public repo: no personal paths, names, emails, or machine-specific details in code or docs. Resolve home with `os.homedir()` and claude from PATH. Windows is primary; macOS/Linux must run (bell-only sound).
- No network calls, no AI, no real system actions (no shutdown, installs, or deletes).
- All user-facing text lives in `src/copy.ts`. Logic modules import copy and never hardcode jokes.
- The user's typed text is never forwarded. Only forwarded rewrites (the `forwardRewrites` list) are sent, always with `FORWARD_GUARD` appended by code: `Answer in text only. Do not read, create, edit, or run anything.`
- Original args reach `claude` unmodified, as an argv array, with `shell: false`.
- Ctrl+C during any gag skips straight to real claude. The terminal must be fully restored before the spawn.
- Normal gags take about 3-7 s. Only the spelling bee and the jackpot wait on input. Strobe at most 3 color changes per second.
- Jackpot odds default 1/20. Never repeat the previous gag.
- State: `~/.calude/state.json` = `{ count: number, lastGag: GagId | null }`. Missing or corrupt means start fresh silently.
- Git: commits and pushes need the owner's explicit go-ahead each time. No Co-Authored-By trailer.

## Review Focus

1. **Args that break when a prompt is appended:** with `-r`/`--resume` (the next token becomes a session id) or a subcommand (`mcp`, `config`, `update`, `doctor`, `install`, `setup-token`, `plugin`, `migrate-installer`), appending a forwarded prompt corrupts the command. Expected: subcommands get their own subcommand gag and are never forwarded a prompt; `-r`/`--resume` still gets a normal gag but no forwarded prompt. (Tests in Task 4.)
2. **Terminal left broken after handoff:** raw mode, a hidden cursor, or a stray color left on when `claude` starts. Expected: `claude`'s UI behaves normally. (Manual check in Task 5.)
3. **Ctrl+C mid-melody:** the PowerShell beep process keeps beeping after claude launches. Expected: the sound stops immediately. (Manual check in Task 5; `stop()` test in Task 5.)
4. **`claude` not found on PATH:** expected: an in-character message and exit code 1, never a stack trace. (Test in Task 4.)
5. **Args with spaces or quotes** (`calude "fix the 'login' bug"`): expected: they arrive intact. (Test in Task 4.)
